# Jayakwadi research package

**Nathsagar — the Jayakwadi story**: a source-cited research and visual package about the Jayakwadi Dam (Paithan, Godavari river, Maharashtra) — engineering profile, the water record 2010–2024, the Nathsagar Bird Sanctuary, and the dam's regional role.

## Open the report

Open `report.html` in any browser (fully self-contained — no internet needed).

## Files

| File | Purpose |

## Headline numbers

- Dam: 41.3 m high, ~10 km long earthen dam on the Godavari at Paithan, inaugurated 24 Feb 1976
- Storage: 2,909.04 Mm³ gross / 2,170.93 Mm³ live
- Command: ~1.83 lakh ha via the 208 km LBC + 132 km RBC
- Sanctuary: 341 km², notified 1986, 234–300+ bird species, Nov–Feb migratory season
- Drought record: dead-storage minimums in 6 of 15 years; 0.5% live storage at the 2016 crisis
